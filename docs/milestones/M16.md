# M16: the real Metro Manila map

Goal: the game ships with every drivable Metro Manila road from OpenStreetMap, and the seven named challenges sit on the real chokepoints.

**Prerequisite:** `overpass-api.de` is reachable from the environment, through the environment's network allowlist.

## 1. Fetch and build

1. `scripts/fetch-osm.sh`, all four quadrants, into `data/osm/q{1..4}.json`. `data/` stays gitignored. Retry a quadrant up to 3 times on HTTP 429 or 504, waiting 60 s between tries.
2. `scripts/build-map.sh`, which writes `web/public/maps/metro-manila.bin.gz`. The file is committed, with the ODbL `LICENSE` beside it.
3. Report the mapgen stats:
   - road, node and point counts
   - gzipped bytes
   - junction count by control
   - roundabout road count
   - areas and holes

   Check them against plan §3.9: about 150k roads, and 20 MB gzipped at most.
4. Change the default map to `metro-manila`. `?map=synthetic` stays available, and so does every e2e test that uses it.

## 2. Network sanity

This is a native test, `crates/sim-core/tests/real_map.rs`. It is `#[ignore]` by default and runs when `TRAPIKS_REAL_MAP=1` is set.

- Every junction builds without a panic. Report the total build time.
- The route graph's largest strongly connected component holds at least 95 % of the active links. Report the share.
- 2,000 random trips of 1–12 km: at least 97 % find a route. Report the mean A* time.

## 3. Challenges on the real map

For each of the seven challenges in `web/public/challenges/metro-manila.json`:

1. Check that the centre falls on the named junction:
   - The nearest node with active degree ≥ 3 must be within 150 m of the centre.
   - Its incident road names must include the named roads. For example, EDSA–Ortigas needs an `EDSA` or `Epifanio de los Santos Avenue` road and an `Ortigas` road.
   - Where the check fails, move the centre to that junction's node position, projected back to lat/lon.
2. Run the release baseline and report its `RunResult` and wall time.
3. Tune `vehicles_per_hour` so the baseline mean delay is 120–400 s with `stranded == 0`, keeping `unserved` under 10 % of `created`.
   - Record each change in the challenge file.
   - Also record each change in this spec's Outcome section, which the orchestrator writes.
4. **Playability check:** show that at least one edit reaching 1 star exists within budget. Try it by script:
   - a flyover at the challenge node
   - a signal retiming
   - a turn ban on the busiest left turn

   Report which one works. If none does, report the numbers and don't change the target.

## 4. Browser

- `e2e/real-map.spec.ts` (`test.setTimeout(180_000)`):
  1. The title screen shows the OSM attribution.
  2. The EDSA–Ortigas challenge measures its baseline.
  3. A screenshot is taken at street zoom over Ortigas with traffic running.

  - EDSA–Ortigas at street zoom
  - one skyway ramp
