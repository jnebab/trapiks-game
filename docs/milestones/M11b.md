# M11b: inspector UI (roads and junctions)

Goal: the player can fix traffic with the mouse.
- Clicking a road opens a road panel. Clicking a junction opens a junction panel.
- Every action shows its cost in a Trafficity-style tooltip chip (`$60 · Add lane`) before the player commits.
- Results update the map, the budget and the panel.
- An Undo chip mirrors Ctrl+Z.

The UI is plain DOM and TypeScript modules with the `.chip` look. No framework.

## Rust

### `sim-core`: `src/edit/inspect.rs` (ts-rs exported)

```rust
pub struct RoadInspection { pub road: u32, pub class: RoadClass, pub length_m: f64,
    pub lanes_forward: u8, pub lanes_backward: u8, pub speed_kph: u8, pub layer: i8, pub deleted: bool }
pub struct TurnInfo { pub from_road: u32, pub to_road: u32, pub kind: TurnKind, pub allowed: bool }
pub struct SignalInfo { pub phase_count: u32, pub greens_s: Vec<u32>, pub offset_s: u32 }
pub struct NodeInspection { pub node: u32, pub control: Control, pub roads: Vec<u32>,
    pub signal: Option<SignalInfo>, pub turns: Vec<TurnInfo>, pub flyover_pairs: Vec<[u32; 2]> }
```

- **`Sim::inspect_road(road) -> Option<RoadInspection>`**
- **`Sim::inspect_node(node) -> Option<NodeInspection>`:**
  - `turns` come from `turns_ignoring_bans`, with `allowed = !banned`, sorted by `(from_road, to_road)`.
  - `flyover_pairs` holds every pair that would pass `BuildFlyover` validation (straightness and length), sorted.
  - `signal` is present when the node belongs to a cluster. `greens_s` are the effective greens, including overrides.
- `TurnKind` derives `TS`.
- Names are resolved on the client from `meta.names` and the road store's `name` column.

### `sim-wasm`

- `inspectRoad(road)` and `inspectNode(node)` return the serialized inspections.

## Protocol

- **Main → worker:** `{ type: 'inspect'; id: number; target: { road: number } | { node: number } }`.
- **Worker → main:** `{ type: 'inspection'; id: number; target: { road: RoadInspection } | { node: NodeInspection } | null }`.
- Guards and tests are included, and `SimClient.inspect(target): Promise<…>`.

## UI (`web/src/hud/inspector/`)

| File | Content |
|---|---|
| `arm-labels.ts` | Pure: `armLabel(road, node, stores)` gives `name + compass letter` (N/E/S/W) from the road's departing direction at the node, using `from`/`to` and the polyline end. Two same-named arms of an avenue are then distinct |
| `panel.ts` | A right-docked card, `role="region"` with an `aria-label`, (`#inspector`, 300 px wide, 12 px margin, white, 1 px `#D6D6D0` border, radius 10, subtle shadow). Hidden when nothing is selected. Reached by `showRoad(info)`, `showNode(info)` and `hide()` |
| `road-view.ts` | Builds the road section from a `RoadInspection` (details below) |
| `node-view.ts` | Builds the junction section from a `NodeInspection` (details below) |
| `view-models.ts` | Pure functions, vitest-covered (details below) |
| `action-button.ts` | `actionButton(label, command: () => EditCommand, client, tooltip)`: a `<button type="button" class="chip">` (details below) |
| `tooltip.ts` | A single floating `.chip.tooltip` element with `role="tooltip"`, positioned at the cursor + (14, 14) px and clamped to the viewport. `showRoad`, `showNode` and `hide` call `tooltip.hide()` |
| `undo-chip.ts` | A top-bar `actionButton` "Undo" for `Undo`. It quotes like any action, so `NothingToUndo` disables it and otherwise the tooltip shows the refund |

**`road-view.ts`:**
- **Header:** the name (or the class name when unnamed), then class · length in m.
- **Lanes:** a "Lanes →" row and a "Lanes ←" row, each a −/+ stepper.
- **Direction:** a segmented chip row: `Two-way`, `One-way →`, `One-way ←`.
- **Speed:** a stepper in steps of 10 km/h.
- **Delete road**, in red text.
- The root element gets `data-lanes-forward`, `data-lanes-backward` and `data-speed`.

**`node-view.ts`:**
- **Header:** "Junction", plus the incident road names.
- **Control:** a segmented chip row: `Priority`, `Yield`, `Stop`, `All-way stop`, `Signal`.
- **Signal timing** (when signalized): one row per phase, each a range input from 5 to 120 s with a numeric label, plus an offset range input from 0 to cycle − 1, and an `Apply timing` button that sends `SetSignalTiming`.
- **Turns:** grouped by `from_road` id, each group titled by its arm label, with one toggle chip per to-road, labelled by kind arrow and arm label. A banned turn is shown struck through.
- **Flyover:** one `Build flyover: A ↔ B` button per pair in `flyover_pairs`, using arm labels.
- After a flyover, a re-inspected node with no junction ring clears the selection.
- The root element gets `data-control` and `data-turns-banned`.

**`view-models.ts`:**
- **`directionCommands(road)`** returns the `SetLanes` for each direction option. The current option's command equals the current lanes, so its quote is `NoChange` and it is disabled with `aria-pressed="true"`. The other options keep the total lane count where possible (`n = 1` becomes (1,1) for two-way):
  - Two-way: `(max(1, ceil(n/2)), max(1, floor(n/2)))`.
  - One-way →: `(min(8, f + b), 0)`.
  - One-way ←: `(0, min(8, f + b))`.
  - The current option is marked.
- **`laneStep(road, dir, delta)`** returns the next `SetLanes`, or `null` when a direction leaves `0..8` or `f + b` would be 0.
- **`speedStep(road, delta)`** returns `null` outside `10..120`.
- **`turnGroups(info, labels)`**, grouped by road id.
- **`flyoverLabel(pair, labels)`**.
- **`costLabel(outcome, label)`** returns `"$60 · Add lane"`, or the `hud/messages.ts` text for an error.

**`action-button.ts`:**
- On `pointerenter`, it asks for a quote, debounced by 80 ms. The result goes to the shared tooltip chip, and the button is disabled on an `Err`.
- While hovered, it re-quotes (debounced) on every `input` event from the panel's sliders, because the command is a thunk.
- Every clickable chip in the panel (segmented options, turn toggles, steppers, action buttons, Undo) is a `<button type="button" class="chip">`. Toggles carry `aria-pressed`. The shared `isEditableTarget` keeps key shortcuts away from them.
- On click, it sends the command.
- On `pointerleave`, it hides the tooltip.

## Controller changes (`edit/edit-controller.ts`)

- **Click:** if `pickNode(x, y, 10 px in metres)` hits, select the node. Otherwise `pickRoad` selects a road. Otherwise clear the selection.
- **Selection:** fetches the inspection and shows the panel. When the selected road or node is in the changed ids of a successful result, it re-inspects. Esc clears the selection.
- **Node selection highlight:** its junction ring is stroked cyan, at 0.6 m width and alpha 0.8, in `layers.selection`.
